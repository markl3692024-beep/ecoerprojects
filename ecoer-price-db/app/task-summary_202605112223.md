# Ecoer 价格查询系统 - 批量上传下载功能 - 2026-05-11

## Objective
为价格查询系统增加批量上传和下载价格清单的功能

## Changes Made

### 1. 新增菜单项
管理员菜单增加 "📥 批量上传/下载" 选项

### 2. 批量上传功能
- 支持 Excel (.xlsx/.xls) 和 CSV 格式
- 必填列: sku, list_price, multiplier
- 可选列: customer_code, effective_date, notes
- 自动验证 SKU 是否存在
- 自动匹配客户编码
- 显示导入结果统计（成功/失败数量）
- 提供 Excel 模板下载

### 3. 下载价格清单功能
- 支持按客户筛选
- 支持按品类筛选
- 显示完整价格信息（SKU/型号/客户/List Price/Multiplier/最终价格）
- 支持 Excel 和 CSV 两种格式下载
- 文件名自动带日期

### 4. 上传模板格式
```
| sku           | customer_code | list_price | multiplier | effective_date | notes     |
|---------------|---------------|------------|------------|----------------|-----------|
| EODA19H-2436  | C001          | 4500.00    | 0.85       | 2026-05-01     | 标准价格  |
| EODA19H-3648  |               | 5200.00    | 0.80       | 2026-05-01     | VIP折扣   |
```

## Access
- 主页: http://localhost:8501
- 进入价格查询系统 → 管理员登录 → 📥 批量上传/下载
