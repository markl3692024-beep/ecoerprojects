# Ecoer 统一入口系统 - 2026-05-11

## Objective
将两个独立系统整合为统一入口页面，支持模块间跳转，价格查询系统需要登录

## Changes Made

### 1. 新建主页 (app/home.py)
- 统一入口页面，居中布局
- 两个模块卡片并排显示：
  - 📊 价格情报系统（竞品分析）
  - 💰 价格查询系统（需登录）
- 点击按钮跳转到对应模块

### 2. 重构价格情报系统 (app/pages/intelligence.py)
- 从 app.py 提取竞品分析功能
- 包含：数据上传、数据查询、价格分析、系统设置
- 侧边栏有返回主页按钮

### 3. 重构价格查询系统 (app/pages/pricing.py)
- 从 ecoer_pricing_tool.py 提取并优化
- 登录后才能使用
- 管理员功能：录入产品、客户、价格、管理用户、数据概览
- Sales Rep 功能：仅价格查询
- 侧边栏有返回主页按钮

### 4. 启动方式变更
```bash
streamlit run app/home.py --server.port 8501
```

## File Structure
```
app/
├── home.py              # 统一入口主页
├── app.py               # 旧版（保留备用）
├── ecoer_pricing_tool.py # 旧版（保留备用）
└── pages/
    ├── intelligence.py  # 价格情报系统
    └── pricing.py       # 价格查询系统
```

## Access
- 主页: http://localhost:8501
- 价格情报: http://localhost:8501/intelligence
- 价格查询: http://localhost:8501/pricing

## Login Credentials
- admin / admin123

## Notes
- 两个数据库仍然完全独立
- 价格查询系统需要登录，价格情报系统不需要
- 可以从任一模块返回主页切换
