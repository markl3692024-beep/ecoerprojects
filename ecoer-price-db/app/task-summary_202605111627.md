# 价格查询工具 V2 - 多层级权限控制 - 2026-05-11

## Objective
创建带权限控制的价格查询系统，不同 Sales Rep 登录后只能看到授权的客户/地区价格

## Key Work Done

### 1. 权限数据库结构 (schema/pricing_system_v2.sql)
新增4张权限相关表：
- **sales_reps**: 销售代表表 (账号/密码/姓名/负责区域)
- **rep_customer_access**: 客户权限关联 (哪个rep能看哪个客户)
- **rep_region_access**: 地区权限关联 (哪个rep能看哪个地区)
- **user_sessions**: 登录会话管理

### 2. 权限控制逻辑
**数据访问控制：**
- Sales Rep 登录后，系统自动过滤其无权访问的客户/地区
- 查询价格时验证：该rep是否有权访问该客户 + 该地区
- 无权访问时返回错误提示

**价格查询优先级：**
1. 客户+地区专属价格
2. 客户通用价格
3. 地区价格
4. 标准价格

**Multiplier 优先级：**
1. 客户+地区+品类
2. 客户+地区
3. 客户+品类
4. 客户
5. 地区+品类
6. 地区
7. 品类
8. 通用

### 4. 界面功能
**登录页面：**
- 用户名/密码登录
- 演示账号快捷入口

**查询界面：**
- 地区选择 (根据权限过滤)
- 客户选择 (根据权限过滤)
- 型号搜索
- 价格计算展示 (List Price → Multiplier → 最终价格)
- 规格参数展示
- 散件清单及价格

**权限概览：**
- 显示当前用户可访问的客户列表
- 显示当前用户可访问的地区列表

**管理员面板：**
- 销售代表管理
- 客户权限分配查看
- 地区权限分配查看
- 价格数据总览
- 系统状态统计
