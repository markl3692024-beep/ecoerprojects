# Ecoer 价格查询系统 V3 - 2026-05-12

## 核心升级: List Price 版本管理

### 新架构
```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│  List Price     │────▶│  Customer        │────▶│  Sales Price    │
│  Versions       │     │  (选择List Price)│     │  (=List×Modifier)│
│  (NE_REG, etc)  │     │  (设置Modifier)  │     │                 │
└─────────────────┘     └──────────────────┘     └─────────────────┘
         │                                               ▲
         │                                               │
         └────────────── 产品明细价格 ────────────────────┘
```

### 数据模型
1. **ecoer_price_lists** - List Price 版本表
   - price_list_code: NE_REG, SE_REG, 2024Q1, etc.
   - 支持多个版本共存

2. **ecoer_list_prices** - 每个版本的产品价格明细
   - price_list_id + product_id + list_price

3. **ecoer_customers** - 客户绑定到特定 List Price
   - price_list_id: 客户使用的 List Price 版本
   - default_modifier: 客户默认折扣系数

4. **ecoer_customer_product_modifiers** - 客户产品专属系数
   - 特定客户购买特定产品的特殊折扣

### 已导入数据
- List Price 版本: NE_REG (Northeast Regular Customer)
- 客户: NE_REG (绑定到 NE_REG List Price, Modifier 100%)
- 产品价格: 101 个

### 功能菜单
1. **🔍 价格查询** - 选择客户 → 搜索产品 → 查看价格
2. **📋 List Price 管理** - 创建版本、查看明细、批量更新
3. **🏢 客户管理** - 创建客户、绑定 List Price、设置 Modifier
4. **📦 产品管理** - 管理产品基础信息
5. **📥 批量上传/下载** - 批量导入/导出价格、Modifier
