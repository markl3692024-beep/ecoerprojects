# Ecoer 价格查询系统 - 干净独立版本 - 2026-05-11

## Objective
创建完全独立的 Ecoer 价格查询系统，所有数据由管理员手动录入，与竞品分析完全分离

## Key Changes

### 1. 数据库完全清空重建 (data/ecoer_pricing.db)
- 删除了之前混入的竞品测试数据
- 现在数据库完全为空，等待管理员录入
- 只包含表结构，没有任何产品/客户/价格数据

### 2. 管理员数据录入界面
新增5个管理Tab：
- **录入产品**: 添加 Ecoer SKU、型号、名称、品类、规格
- **录入客户**: 添加客户编码、名称、类型、折扣等级
- **录入价格**: 为产品设置 List Price 和 Multiplier
- **管理用户**: 创建销售代表账号，分配客户权限
- **数据概览**: 查看系统统计

### 3. 数据录入流程
```
1. 管理员登录 (admin / admin123)
2. 录入 Ecoer 产品 (SKU/型号/规格)
3. 录入客户信息 (编码/名称/折扣等级)
4. 设置产品价格 (List Price + Multiplier)
5. 创建销售代表账号 (分配可访问的客户)
6. Sales Rep 登录查询价格
```

### 4. 与竞品分析系统的关系
| 系统 | 数据库 | 用途 |
|------|--------|------|
| 竞品分析 | data/ecoer_prices.db | Bryant/Goodman 等竞品价格分析 |
| 价格查询 | data/ecoer_pricing.db | Ecoer 产品价格查询 (独立) |

两个系统完全独立，数据不互通
